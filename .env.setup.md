# 🔧 Guía de Configuración del Archivo .env

Esta guía te ayudará a configurar correctamente tu archivo `.env` para el proyecto BitgetTrade.

## 📋 Pasos Iniciales

### 1. Copiar el archivo de ejemplo

```bash
copy .env.example .env
```

### 2. Generar la clave de aplicación

```bash
php artisan key:generate
```

Esto generará automáticamente una clave segura en `APP_KEY`.

## ⚙️ Configuraciones Importantes

### 🏷️ Identificación de la Aplicación

```env
APP_NAME="BitgetTrade"
APP_URL=http://localhost
```

- **APP_NAME**: Nombre que aparecerá en el navegador y emails
- **APP_URL**: URL donde se ejecuta tu aplicación (cambiar en producción)

### 🔐 Modo de Desarrollo vs Producción

Para **desarrollo local**:
```env
APP_ENV=local
APP_DEBUG=true
```

Para **producción** (cuando subas a un servidor):
```env
APP_ENV=production
APP_DEBUG=false
```

⚠️ **IMPORTANTE**: Nunca dejes `APP_DEBUG=true` en producción, ya que expondrá información sensible.

### 💾 Base de Datos

Por defecto, el proyecto usa **SQLite** (no requiere instalación):

```env
DB_CONNECTION=sqlite
```

El archivo de base de datos se creará en: `database/database.sqlite`

#### Alternativa: Usar MySQL/MariaDB

Si prefieres MySQL:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=bitget_laravel
DB_USERNAME=root
DB_PASSWORD=tu_password_aqui
```

Luego crea la base de datos:
```bash
mysql -u root -p
CREATE DATABASE bitget_laravel;
exit;
```

## 🔑 Configuración de Bitget API

### ✅ IMPORTANTE: Gestión desde Base de Datos

**Las credenciales de Bitget ya NO se configuran en el archivo `.env`**

Todas las cuentas API de Bitget ahora se gestionan directamente desde la interfaz web de la aplicación. Esto permite:

- 🔐 **Mayor seguridad**: Las credenciales no están en archivos de texto plano
- 👥 **Multi-cuenta**: Cada usuario puede tener múltiples cuentas API
- 🎯 **Gestión fácil**: Agregar, editar o eliminar cuentas desde la interfaz
- 📊 **Organización**: Etiquetar cuentas (ej: "Cuenta Principal", "Cuenta Demo")

### 📝 Cómo agregar tus cuentas de Bitget

Una vez que la aplicación esté funcionando:

1. **Inicia sesión** en la aplicación
2. Ve a la sección **"Cuentas API"** en el menú
3. Haz clic en el botón **"Agregar Cuenta"**
4. Completa el formulario con:
   - Nombre de la cuenta (ej: "Cuenta Principal")
   - API Key
   - Secret Key
   - Passphrase
5. Guarda la cuenta

### 🔒 Cómo obtener tus credenciales de Bitget

1. **Inicia sesión en Bitget**
   - Ve a: https://www.bitget.com
   - Accede a tu cuenta

2. **Navega a API Management**
   - Menú → Cuenta → API Management
   - O directamente: https://www.bitget.com/account/newapi

3. **Crea una nueva API Key**
   - Haz clic en "Create API"
   - Dale un nombre descriptivo (ej: "Laravel App")
   - Configura los permisos:
     - ✅ **Read** (Lectura)
     - ❌ **Trade** (NO marcar)
     - ❌ **Withdraw** (NO marcar)

4. **Guarda las credenciales**
   - **API Key**: Comienza con `bg_`
   - **Secret Key**: Cadena larga alfanumérica
   - **Passphrase**: La contraseña que tú defines

⚠️ **IMPORTANTE**:
- Guarda estas credenciales en un lugar seguro
- Solo se mostrarán UNA VEZ
- NUNCA las compartas con nadie
- Ingresa estas credenciales en la aplicación web, NO en el .env

## 📧 Configuración de Email (Opcional)

Para desarrollo, los emails se guardan en los logs:

```env
MAIL_MAILER=log
```

Para usar un servicio real (Mailtrap, Gmail, etc.):

```env
MAIL_MAILER=smtp
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=tu_username
MAIL_PASSWORD=tu_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS="noreply@bitgettrade.com"
MAIL_FROM_NAME="BitgetTrade"
```

## ✅ Verificar la Configuración

Después de configurar tu `.env`, ejecuta:

```bash
# Limpiar cachés
php artisan config:clear
php artisan cache:clear

# Verificar que todo esté bien
php artisan config:show app
```

## 🚨 Seguridad - Lista de Verificación

Antes de subir a producción:

- [ ] `APP_DEBUG=false`
- [ ] `APP_ENV=production`
- [ ] Credenciales de base de datos seguras
- [ ] `.env` en `.gitignore` (ya incluido)
- [ ] `APP_KEY` generada y única
- [ ] URLs de aplicación correctas
- [ ] Permisos de API de Bitget solo de lectura

## 🆘 Problemas Comunes

### Error: "No application encryption key has been specified"

```bash
php artisan key:generate
```

### Error: "Could not find driver" (SQLite)

Habilita la extensión en `php.ini`:
```ini
extension=pdo_sqlite
extension=sqlite3
```

### Error de conexión con Bitget

1. Verifica que las credenciales sean correctas
2. Asegúrate de que `BITGET_BASE_URL=https://api.bitget.com`
3. Verifica que la API Key tenga permisos de lectura
4. Revisa que el firewall no bloquee conexiones a Bitget

### La aplicación muestra errores

```bash
php artisan config:clear
php artisan cache:clear
php artisan view:clear
composer dump-autoload
```

## 🔄 Actualizar Configuración

Cada vez que modifiques el `.env`:

```bash
php artisan config:clear
```

O reinicia el servidor de desarrollo:

```bash
# Ctrl+C para detener
php artisan serve
```
